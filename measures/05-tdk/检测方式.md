# TDK 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| title 存在 | 解析 `<title>` 标签 | 每页有 title | ✅ 脚本 |
| title 唯一性 | 对比多页面 title | 无重复 | ✅ 脚本 |
| title 格式 | 解析内容 | 遵循"页面内容 - 网站名称"模式 | 🟡 半自动 |
| description 存在 | 解析 `<meta name="description">` | 每页有 description | ✅ 脚本 |
| description 唯一性 | 对比多页面 | 无重复 | ✅ 脚本 |
| keywords 存在 | 解析 `<meta name="keywords">` | 每页有 keywords（优先级低） | ✅ 脚本 |

## 自动化检查

- 检查脚本：`workflow/scripts/check-tdk.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/tdk-stats.json`

## 人工检查要点

- title 是否遵循"页面内容 - 网站名称"模式
- description 是否概括页面内容而非关键字堆砌
