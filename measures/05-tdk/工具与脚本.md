# TDK 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-tdk | workflow/scripts/check-tdk.mjs | 校验各项目页面 title/description/keywords 的存在性与唯一性 | `node workflow/scripts/check-tdk.mjs` |
| check-tdk-duplicate | workflow/scripts/check-tdk-duplicate.mjs | 按 sitemap 全量页面逐页请求 HTML，检查各项目 TDK 重复项（分组判重，逻辑参考 seo-check/scripts/description-check.js） | `node workflow/scripts/check-tdk-duplicate.mjs [--site=ID] [--conc=10] [--max=N] [--skip=a,b]` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-tdk.mjs

# 检查单个项目
node workflow/scripts/check-tdk.mjs --site openEuler-portal

# TDK 重复检查（默认跳过 openEuler-docs/openGauss-docs/MindSpore-docs 三个 docs 大站，--skip= 传空可全查）
node workflow/scripts/check-tdk-duplicate.mjs

# 只查单个项目 / 限制页数试跑
node workflow/scripts/check-tdk-duplicate.mjs --site=HiFloat
node workflow/scripts/check-tdk-duplicate.mjs --site=openEuler-portal --max=200
```

## 输出

- 汇总报告：直接写入 `manual-review/issues/tdk/tdk-duplicate-report-YYYY-MM-DD.md`
- 完整重复组数据：`workflow/stats/tdk-duplicate-stats.json`
