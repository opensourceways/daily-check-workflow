# TDK 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-tdk | workflow/scripts/check-tdk.mjs | 校验各项目页面 title/description/keywords 的存在性与唯一性 | `node workflow/scripts/check-tdk.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-tdk.mjs

# 检查单个项目
node workflow/scripts/check-tdk.mjs --site openEuler-portal
```
