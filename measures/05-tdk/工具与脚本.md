# TDK 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-tdk | workflow/scripts/check-tdk.mjs | 校验各项目页面 title/description/keywords 的存在性与唯一性 | `node workflow/scripts/check-tdk.mjs` |
| check-tdk-duplicate | workflow/scripts/check-tdk-duplicate.mjs | 按 sitemap 全量页面逐页请求 HTML，检查各项目 TDK 重复项（分组判重，逻辑参考 seo-check/scripts/description-check.js） | `node workflow/scripts/check-tdk-duplicate.mjs [--site=ID] [--conc=10] [--max=N] [--skip=a,b] [--submit-issues] [--dry-run]` |
| atomgit 客户端 | workflow/lib/atomgit.mjs | AtomGit API v5 轻量封装（列 issue/按前缀查重/建 issue/评论），零依赖基于全局 fetch | 供 `--submit-issues` 模式使用 |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-tdk.mjs

# 检查单个项目
node workflow/scripts/check-tdk.mjs --site openEuler-portal

# TDK 重复检查（默认跳过 openEuler-docs/openGauss-docs/MindSpore-docs 三个 docs 大站，--skip= 传空可全查）
node workflow/scripts/check-tdk-duplicate.mjs

# 只查单个项目 / 限制页数试跑
node workflow/scripts/check-tdk-duplicate.mjs --site=HiFloat
node workflow/scripts/check-tdk-duplicate.mjs --site=openEuler-portal --max=200

# 定时提 issue 模式（GitHub Actions 中执行；需 ATOMGIT_TOKEN；本地试跑可用 --dry-run 只打印正文）
node workflow/scripts/check-tdk-duplicate.mjs --submit-issues [--site=ID] [--dry-run]
```

## 输出

- 汇总报告：直接写入 `scheduled-reports/tdk/YYYY-MM-DD/report.md`（按日期分目录）（手动模式含全部明细；`--submit-issues` 模式仅含总览，明细指向各项目完全版文件）
- 完整重复组数据：`workflow/stats/tdk-duplicate-stats.json`
- `--submit-issues` 模式额外输出（每项目，仅当发现重复）：`scheduled-reports/tdk/<日期目录>/<ID>-brief.md`（简短版，issue 正文用）与 `<ID>-full.md`（完全版，含全部明细，issue 链接指向它，由 workflow 提交回仓库）
