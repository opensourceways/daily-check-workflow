# robots.txt 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-robots | workflow/scripts/check-robots.mjs | 校验各项目 robots.txt 字段完整性、Content-Signal、LLM-Policy | `node workflow/scripts/check-robots.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-robots.mjs

# 检查单个项目
node workflow/scripts/check-robots.mjs --site openEuler-portal
```
