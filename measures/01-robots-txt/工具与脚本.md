# robots.txt 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-robots | workflow/scripts/check-robots.mjs | 完整规范检查并自动生成 md 报告：可访问性（主域+alias）、User-agent、allow/disallow 存在性与路径起始斜杠、整站封锁判定、Sitemap/LLM-Policy 链接可达、Content-Signal 取值比对（规则见 config/check-rules.json 的 `robots.contentSignalExpected`）、LLM-Policy 指向 llms.txt、主域/alias 内容一致性、跨域引用告警；输出 stats JSON + `manual-review/issues/robotstxt/YYYY-MM-DD-robots-规范检查报告.md`，每项目给出 hardErrors/warnings/verdict | `node workflow/scripts/check-robots.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-robots.mjs

# 检查单个项目
node workflow/scripts/check-robots.mjs --site=openEuler-portal
```

## 输出

- 脚本结果：`workflow/stats/robots-stats.json`（每项目含 checks（主域）、alias（alias 域）、aliasConsistent、hardErrors、warnings、verdict）
- Markdown 报告（脚本自动生成）：`manual-review/issues/robotstxt/YYYY-MM-DD-robots-规范检查报告.md`（总览表 + 各项目明细 + 结论与建议）
- 2026-10-12 首轮人工核查报告：`manual-review/issues/robotstxt/robots-spec-report-2026-10-12.md`（历史快照，同等检查已并入脚本）
