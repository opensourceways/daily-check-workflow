# robots.txt 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| robots.txt 可访问 | HTTP GET /robots.txt | 200 状态码 | ✅ 脚本 |
| User-agent 存在 | 解析文件内容 | 至少一条 User-agent | ✅ 脚本 |
| disallow/allow 路径规范 | 解析路径 | 以 `/` 开头，目录以 `/` 结尾 | ✅ 脚本 |
| sitemap 声明存在且可访问 | 解析并 GET | sitemap URL 可访问 | ✅ 脚本 |
| Content-Signal 存在 | 解析文件内容 | 包含 ai-train/search/ai-input | ✅ 脚本 |
| LLM-Policy 存在且指向 llms.txt | 解析文件内容 | 指向有效 llms.txt | ✅ 脚本 |

## 自动化检查

- 检查脚本：`workflow/scripts/check-robots.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/robots-stats.json`

## 人工检查要点

- UnifiedBus 的 disallow 规则是否误伤正常页面
- MindSpore 文档 / openUBMC 文档 是否需要独立 robots.txt
