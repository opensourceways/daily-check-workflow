# Sitemap 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-sitemap | workflow/scripts/check-sitemap.mjs | 校验各项目 sitemap.xml 的 loc/lastmod/changefreq/xhtml:link 规范性及可访问性 | `node workflow/scripts/check-sitemap.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-sitemap.mjs

# 检查单个项目
node workflow/scripts/check-sitemap.mjs --site openEuler-portal
```
