# Sitemap 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| sitemap-spec-check（当前主要） | workflow/scripts/sitemap-spec-check.mjs | sitemap 属性规范检查：urlset/index 递归解析（子 sitemap 可访问性、newVersions 过滤）、loc 绝对性与合法域名清单（domain/domainAlias/sitemapUrl/sitemapAliasUrl）、lastmod W3C 格式/未来时间/构建时间启发式、changefreq 枚举与 never、xhtml:link 按语言路径规则 + 页面全集核实；生成汇总报告 + 缺失/不符合条目完整明细 | `node workflow/scripts/sitemap-spec-check.mjs --skip=MindSpore-docs` |
| check-sitemap（旧版轻量快查） | workflow/scripts/check-sitemap.mjs | 单次抽样统计（JSON），口径较粗，规范判定以 sitemap-spec-check 为准 | `node workflow/scripts/check-sitemap.mjs --site=<项目id>` |

## 使用说明

```bash
# 完整规范检查（跳过 MindSpore 文档；--skip 支持逗号分隔多个项目 id）
node workflow/scripts/sitemap-spec-check.mjs --skip=MindSpore-docs

# 或在 workflow 目录下用 package.json 别名
pnpm check:sitemap-spec -- --skip=MindSpore-docs

# 旧版快查（单项目）
node workflow/scripts/check-sitemap.mjs --site=openEuler-portal
```

## 输出

脚本直接写入报告归档目录 `manual-review/issues/sitemap/`（不再经 `reports/` 中转）：

| 文件 | 内容 |
|------|------|
| manual-review/issues/sitemap/YYYY-MM-DD-sitemap-规范检查报告.md | 总览表 + 各项目明细（分类计数、错误/告警、loc 抽样访问、newVersions/domainAlias 等特殊约定说明），并链接明细文件 |
| manual-review/issues/sitemap/YYYY-MM-DD-sitemap-问题条目明细.md | 缺失/不符合条目完整清单，按项目、属性分类；单类超上限截断并注明总数（硬性错误 3000、缺失类 2000、域名不一致 1000） |
| workflow/stats/sitemap-stats.json | 旧版快查脚本的统计输出 |

## 依赖的配置字段（projects.config.json）

| 字段 | 作用 |
|------|------|
| sitemapUrl | 待检查的 sitemap（urlset 或 index） |
| sitemapAliasUrl | 别名域 sitemap，其 host 计入合法域名清单 |
| domainAlias | 别名域名，其 host 计入合法域名清单（loc 指向它不算问题） |
| newVersions | index 项目仅检查匹配这些版本路径（`/` 为根）的子 sitemap；index 缺项时告警 |
| langMode（可选） | 覆盖 xhtml:link 语言路径规则：`zh-en-prefix`（默认）或 `mindspore`；缺省时按项目 id 是否含 MindSpore 推断 |

## 解析限制

- 报告生成与检查合一：脚本直接抓取现网 sitemap，不读取本地构建产物
- 子 sitemap 最多检查前 50 个（超出在报告中注明）
- xhtml:link 核实以 sitemap 收录的 URL 全集为依据，站点存在但未收录的语言版本无法发现（见 检测方式.md 人工检查要点）
