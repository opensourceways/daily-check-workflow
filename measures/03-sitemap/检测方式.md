# Sitemap 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| sitemap.xml 可访问 | HTTP GET | 200 状态码 | ✅ 脚本 |
| loc 地址符合规范 | 解析 XML | 以 http/https 开头的完整 URL | ✅ 脚本 |
| loc 能正常访问 | HTTP GET 每个 loc | 200 状态码（抽样） | ✅ 脚本 |
| lastmod 正常 | 解析 XML | W3C 格式，非所有页面相同值（非构建时间） | ✅ 脚本 |
| changefreq 合理 | 解析 XML | 非 never（除非已归档） | ✅ 脚本 |
| xhtml:link 完整性 | 解析 XML | 多语言页面包含 alternate 声明 | ✅ 脚本 |
| sitemap_index 可访问性 | HTTP GET 各子 sitemap | 所有子 sitemap 可访问 | ✅ 脚本 |

## 自动化检查

- 检查脚本：`workflow/scripts/check-sitemap.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/sitemap-stats.json`

## 人工检查要点

- 定期人工巡查现网 sitemap.xml 内域名是否正确（921 事故规避）
- 定期巡查现网 sitemap 地址是否可访问
- 多个 Vitepress 项目间 sitemap index 生成逻辑是否同步
