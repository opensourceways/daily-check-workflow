# Sitemap 规范

## 规范来源

- [sitemaps.org - Home](https://www.sitemaps.org/)
- [Google 搜索中心：站点地图](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview?hl=zh-cn)

## 规范定义

| 属性 | 必选 | 规范说明 |
|------|------|----------|
| loc | 是 | 页面的 URL。该 URL 必须以协议（如 http）开头 |
| lastmod | 否 | 该页面的最后修改日期。该日期应采用 W3C 日期时间格式。此格式允许根据需要省略时间部分，使用 YYYY-MM-DD 格式。该日期必须设置为链接**页面的最后修改日期，而非 sitemap 的生成日期**。 |
| changefreq | 否 | 该页面预计的更新频率。有效值包括：`always`, `hourly`, `daily`, `weekly`, `monthly`, `yearly`, `never`。应使用 `always` 值来描述每次访问时都会发生变化的文档。应使用 `never` 值来描述已归档的URL。此标签的值仅被视为提示，而非指令。 |
| xhtml:link | 否 | 当页面存在其他语言版本，则包含该页面的 `<url>` 中应该用 `<xhtml:link rel="alternate" hreflang="" href=""/>` 列出网页每个语言版本（包括自身） |

## 关键要求

1. loc 必须以协议（http/https）开头，必须是完整 URL
2. lastmod 必须反映页面真实最后修改时间，而非构建时间
3. changefreq 应合理设置，避免无意义地设为 never
4. 多语言页面必须包含 xhtml:link alternate 声明所有语言版本
