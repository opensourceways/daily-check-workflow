# a 标签语义 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| 无语义链接文本 | 解析 a 标签文本，匹配黑名单词（"点击这里""更多""这里""learn more"） | 无匹配 | ✅ 脚本 |
| href 有效性 | 检查 href 非空、非 `#`、非 `javascript:` | 全部有效 | ✅ 脚本 |
| 外链 rel 规范 | 检查 target=_blank 的 a 标签是否有 rel="noopener" | 全部符合 | ✅ 脚本 |
| 锚点有效性 | 校验站内锚点指向的 id 存在 | 全部有效 | ✅ 脚本 |
| 图片链接 alt | 检查仅含 img 的 a 标签，img 是否有 alt | 全部有 alt | ✅ 脚本 |

## 自动化检查

### 规范抽查（当前主要）

- 检查脚本：`workflow/scripts/semantic-spec-check.mjs`（06/07/08 三项规范一次抽查；抽样范围与解析口径见 measures/08-image-alt/检测方式.md）
- 执行方式：`node workflow/scripts/semantic-spec-check.mjs`
- 检测口径：
  - 无语义链接文本（a.badText，必选）：链接可见文本去空格转小写后**整串精确匹配**黑名单（`check-rules.json` 的 `badLinkTextBlacklist`）
  - javascript: 伪协议（a.jsHref，必选）：href 以 `javascript:` 开头
  - href 空/缺失/#（a.invalidHref，必选）：无 href 属性、空串、`#`、`#!`
  - 外链缺 noopener（a.extNoRel，必选）：跨源 http(s) 链接且 `target="_blank"` 且 rel 不含 `noopener`（仅 `noreferrer` 也计问题）
  - 图片链接缺 alt（a.imgLinkNoAlt，必选）：`<a>` 无文本仅含图片且 img 缺 alt 属性
  - 锚点有效性（a.brokenAnchor，建议级）：`#fragment`（`#top` 除外）在本页找不到对应 id
- 输出：`workflow/stats/semantic-spec-stats.json` + `manual-review/issues/semantic/YYYY-MM-DD-html语义化-抽查报告.md`

### 基线统计（仅站点首页）

- 检查脚本：`workflow/scripts/check-a-tag.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/a-tag-stats.json`

## 人工检查要点

- 链接文本是否描述目标页内容
- 导航/列表组件中的链接文本是否语义化
