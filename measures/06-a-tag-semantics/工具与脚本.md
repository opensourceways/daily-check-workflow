# a 标签语义 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-a-tag | workflow/scripts/check-a-tag.mjs | 检测无语义链接文本、无效 href、缺失 rel 的外链 | `node workflow/scripts/check-a-tag.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-a-tag.mjs

# 检查单个项目
node workflow/scripts/check-a-tag.mjs --site openEuler-portal
```
