# a 标签语义 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | workflow/scripts/semantic-spec-check.mjs | 以 measures/10「检查细节」为核心（a.noHref/a.noText/a.badHref/a.jsHref），本措施附加项：无语义文本/`#` 占位/外链缺 noopener/失效锚点；生成 stats JSON + scheduled-reports 报告 | `node workflow/scripts/semantic-spec-check.mjs` |
| check-a-tag | workflow/scripts/check-a-tag.mjs | 各项目站点首页的 a 标签聚合统计（基线） | `node workflow/scripts/check-a-tag.mjs` |

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 scheduled-reports/semantic/）
node workflow/scripts/semantic-spec-check.mjs

# 基线统计：检查所有项目首页
node workflow/scripts/check-a-tag.mjs

# 基线统计：检查单个项目
node workflow/scripts/check-a-tag.mjs --site openEuler-portal
```
