# a 标签语义 规范

## 规范来源

- [HTML `<a>` 元素 — MDN](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/a)
- [链接文本最佳实践 — Google 搜索中心](https://developers.google.com/search/docs/appearance/link-text?hl=zh-cn)
- [WCAG 2.1 — 链接文本](https://www.w3.org/WAI/WCAG21/Understanding/link-purpose-in-context.html)

## 规范定义

| 属性/规范点 | 必选 | 规范说明 |
|-------------|------|----------|
| href | 是 | 指向有效资源，非空且非 `#`/`javascript:` |
| 链接文本语义 | 是 | 链接文本应描述目标页面内容，避免"点击这里""更多"等无语义文本 |
| rel | 否 | 根据场景使用 `noopener`/`noreferrer`/`nofollow` 等 |
| target | 否 | 外链使用 `target="_blank"` 时应同时设置 `rel="noopener"` |
| 锚点链接 | 否 | 站内跳转的锚点应指向真实存在的目标元素 |

## 关键要求

1. 链接文本必须具有描述性，能让用户和 AI 理解目标页内容
2. 禁止使用"点击这里""了解更多""这里"等无语义链接文本
3. 外链必须设置 `rel="noopener"`（防止 tabnabbing）
4. href 禁止使用 `javascript:` 协议
5. 图片链接必须提供 alt 作为替代链接文本
