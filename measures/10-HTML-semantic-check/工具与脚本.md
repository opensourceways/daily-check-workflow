# HTML 语义化 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | scripts/checks/semantic-spec-check.mjs | 以本措施「检查细节」为核心（header/footer/main/h1~h6/img alt/a 的缺失·重复·层级结构判定，含元素树解析与可见性判定），并输出 06/07/08 附加项；`--submit-issues` 支持提单（前缀 `[GEO HTML Semantic]`，brief/full 双报告，查重跳过；`--force` 强制执行时对原未关闭 issue 更新/评论 /close 写回）；生成 stats JSON + scheduled-reports 抽查报告 | `node scripts/checks/semantic-spec-check.mjs [--site=ID] [--skip=] [--submit-issues] [--dry-run] [--force]` |

## GitHub Action

- Workflow：`.github/workflows/html-semantic-check.yml`（每周三 05:30 UTC 定时 + `workflow_dispatch` 手动，inputs：`site`/`dry_run`/`force_check`——勾选 force_check 后透传 `--force` 强制执行，跳过查重拦截并写回原 issue）
- 运行：`--submit-issues`，环境变量 `ATOMGIT_TOKEN`（secrets）；报告 commit 回本仓库 `scheduled-reports/semantic/<YYYY-MM-DD>/`
- 注意：cron 定时仅在默认分支（main）生效，archive 分支合入 main 前用 workflow_dispatch 验证

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 scheduled-reports/semantic/<YYYY-MM-DD>/）
node scripts/checks/semantic-spec-check.mjs

# 提单模式（需 ATOMGIT_TOKEN；已有未关闭同前缀 issue 的项目跳过扫描；--dry-run 只打印正文不写回）
node scripts/checks/semantic-spec-check.mjs --submit-issues [--site=ID] [--dry-run]

# 强制执行（修复后立即复核：已有未关闭 issue 不再跳过，仍有问题更新原 issue，已无问题评论 /close）
node scripts/checks/semantic-spec-check.mjs --submit-issues --force --site=ID
```

## 报告输出

- 抽查报告：`scheduled-reports/semantic/YYYY-MM-DD/report.md`（总览 + 问题类型汇总 + 各项目逐页明细 + 共性问题概览）；提单模式 brief/full 为同目录 `<ID>-brief.md`/`<ID>-full.md`
- 抽查明细数据：`scripts/stats/semantic-spec-stats.json`
- 产物按日期分目录：`scheduled-reports/semantic/<YYYY-MM-DD>/`（汇总报告 + 提单模式 brief/full）
