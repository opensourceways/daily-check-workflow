# HTML 语义化 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | workflow/scripts/semantic-spec-check.mjs | 以本措施「检查细节」为核心（header/footer/main/h1~h6/img alt/a 的缺失·重复·层级结构判定，含元素树解析与可见性判定），并输出 06/07/08 附加项；`--submit-issues` 支持提单（前缀 `[GEO HTML Semantic]`，brief/full 双报告，查重跳过）；生成 stats JSON + manual-review 抽查报告 | `node workflow/scripts/semantic-spec-check.mjs [--site=ID] [--skip=] [--submit-issues] [--dry-run]` |

## GitHub Action

- Workflow：`.github/workflows/html-semantic-check.yml`（每周三 05:30 UTC 定时 + `workflow_dispatch` 手动，inputs：`site`/`dry_run`）
- 运行：`--submit-issues`，环境变量 `ATOMGIT_TOKEN`（secrets）；报告 commit 回本仓库 `manual-review/issues/semantic/<YYYY-MM-DD>/`
- 注意：cron 定时仅在默认分支（main）生效，archive 分支合入 main 前用 workflow_dispatch 验证

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 manual-review/issues/semantic/<YYYY-MM-DD>/）
node workflow/scripts/semantic-spec-check.mjs
```

## 报告输出

- 抽查报告：`manual-review/issues/semantic/YYYY-MM-DD/report.md`（总览 + 问题类型汇总 + 各项目逐页明细 + 共性问题概览）；提单模式 brief/full 为同目录 `<ID>-brief.md`/`<ID>-full.md`
- 抽查明细数据：`workflow/stats/semantic-spec-stats.json`
- 产物按日期分目录：`manual-review/issues/semantic/<YYYY-MM-DD>/`（汇总报告 + 提单模式 brief/full）
