# 图片 alt 语义 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-image-alt | workflow/scripts/check-image-alt.mjs | 检测 img 标签 alt 属性缺失、空 alt 处理、alt 文本质量 | `node workflow/scripts/check-image-alt.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-image-alt.mjs

# 检查单个项目
node workflow/scripts/check-image-alt.mjs --site openEuler-portal
```
