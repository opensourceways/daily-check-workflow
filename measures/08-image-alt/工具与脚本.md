# 图片 alt 语义 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | workflow/scripts/semantic-spec-check.mjs | 以 measures/10「检查细节」为核心（含 i.noAlt：`<img>` 不存在 alt 属性，`alt=""` 不计缺失），本措施附加项：黑名单精确匹配、>125 字符、同页重复 ≥3；生成 stats JSON + manual-review 报告 | `node workflow/scripts/semantic-spec-check.mjs` |
| check-image-alt | workflow/scripts/check-image-alt.mjs | 各项目站点首页的 alt 缺失率/无意义 alt 聚合统计（基线） | `node workflow/scripts/check-image-alt.mjs` |

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 manual-review/issues/semantic/）
node workflow/scripts/semantic-spec-check.mjs

# 基线统计：检查所有项目首页
node workflow/scripts/check-image-alt.mjs

# 基线统计：检查单个项目
node workflow/scripts/check-image-alt.mjs --site openEuler-portal
```

## 报告输出

- 抽查报告：`manual-review/issues/semantic/YYYY-MM-DD-html语义化-抽查报告.md`（总览 + 问题类型汇总 + 各项目逐页明细 + 共性问题概览）
- 抽查明细数据：`workflow/stats/semantic-spec-stats.json`
