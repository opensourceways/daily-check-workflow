# 图片 alt 语义 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| alt 属性存在 | 解析所有 `<img>` | 每个 img 都有 alt 属性 | ✅ 脚本 |
| alt 缺失率 | 统计缺失 alt 的 img 占比 | 缺失率为 0 | ✅ 脚本 |
| 无意义 alt | 匹配黑名单词（"图片""image""photo""截图"等） | 无匹配 | ✅ 脚本 |
| alt 文本长度 | 检查 alt 长度 | 不超过 125 字符 | ✅ 脚本 |
| 装饰图处理 | 检查背景图/CSS 图是否用了 img 且 alt="" | 装饰图用空 alt | ✅ 脚本 |
| alt 重复 | 检查同页面 alt 是否大量重复 | 无大量重复 | ✅ 脚本 |

## 自动化检查

### 规范抽查（当前主要）

- 检查脚本：`workflow/scripts/semantic-spec-check.mjs`（06/07/08 三项规范一次抽查）
- 执行方式：`node workflow/scripts/semantic-spec-check.mjs`
- 抽样范围：门户类项目 = 首页 + sitemap 中至多 4 个不同栏目页（meta-refresh 自动跟随）；文档类项目仅查首页（openEuler-docs/openGauss-docs 查 `/zh/`、`/en/`，openUBMC-docs 查 `/docs/zh/latest`、`/docs/en/latest`）；MindSpore-docs 跳过
- 解析口径：线上静态/SSR HTML 剔除 `<script>`/`<style>`/注释/`<noscript>` 后正则解析；纯 CSR 壳页面记为 07「客户端渲染壳」问题，不做 alt 统计
- 检测口径：
  - `<img>` 缺 alt（i.missingAlt，必选）：**仅检查 alt 属性是否存在**；`alt=""` 视为装饰图、不计缺失
  - 无意义 alt（i.badAlt，必选）：alt 去空格转小写后**整串精确匹配**黑名单（`workflow/config/check-rules.json` 的 `badAltBlacklist`）
  - alt 超长（i.longAlt，建议）：alt 超过 125 字符
  - 同页 alt 重复（i.dupAlt，建议）：同一非空 alt 出现 ≥3 次
  - 图片链接缺 alt（a.imgLinkNoAlt，06 侧，必选）：`<a>` 无文本仅含图片且 img 缺 alt 属性
- 输出：`workflow/stats/semantic-spec-stats.json`（明细）+ `manual-review/issues/semantic/YYYY-MM-DD-html语义化-抽查报告.md`

### 基线统计（仅站点首页）

- 检查脚本：`workflow/scripts/check-image-alt.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/image-alt-stats.json`

## 人工检查要点

- alt 文本是否准确描述图片内容
- 图表/示意图是否有详细 alt
- 装饰性图片是否正确使用空 alt
