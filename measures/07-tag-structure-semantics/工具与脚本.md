# 标签结构语义化 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | scripts/checks/semantic-spec-check.mjs | 以 measures/10「检查细节」为核心（header/footer/main/h1~h6 的缺失·重复·自嵌套），本措施附加项：缺 `<nav>`、客户端渲染壳、div/区块规模统计；生成 stats JSON + scheduled-reports 报告 | `node scripts/checks/semantic-spec-check.mjs` |
| check-tag-structure | scripts/checks/check-tag-structure.mjs | 各项目站点首页的 h1/标题/语义区块/div 聚合统计（基线） | `node scripts/checks/check-tag-structure.mjs` |

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 scheduled-reports/semantic/）
node scripts/checks/semantic-spec-check.mjs

# 基线统计：检查所有项目首页
node scripts/checks/check-tag-structure.mjs

# 基线统计：检查单个项目
node scripts/checks/check-tag-structure.mjs --site openEuler-portal
```
