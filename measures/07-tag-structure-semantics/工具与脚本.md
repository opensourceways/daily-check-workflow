# 标签结构语义化 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| semantic-spec-check（当前主要） | workflow/scripts/semantic-spec-check.mjs | 以 measures/10「检查细节」为核心（header/footer/main/h1~h6 的缺失·重复·自嵌套），本措施附加项：缺 `<nav>`、客户端渲染壳、div/区块规模统计；生成 stats JSON + manual-review 报告 | `node workflow/scripts/semantic-spec-check.mjs` |
| check-tag-structure | workflow/scripts/check-tag-structure.mjs | 各项目站点首页的 h1/标题/语义区块/div 聚合统计（基线） | `node workflow/scripts/check-tag-structure.mjs` |

## 使用说明

```bash
# 抽查全部项目（抽样页面，输出问题报告到 manual-review/issues/semantic/）
node workflow/scripts/semantic-spec-check.mjs

# 基线统计：检查所有项目首页
node workflow/scripts/check-tag-structure.mjs

# 基线统计：检查单个项目
node workflow/scripts/check-tag-structure.mjs --site openEuler-portal
```
