# 标签结构语义化 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-tag-structure | workflow/scripts/check-tag-structure.mjs | 检测 h1 唯一性、标题层级跳级、div 滥用、缺失语义区块标签 | `node workflow/scripts/check-tag-structure.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-tag-structure.mjs

# 检查单个项目
node workflow/scripts/check-tag-structure.mjs --site openEuler-portal
```
