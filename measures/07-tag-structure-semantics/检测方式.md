# 标签结构语义化 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| h1 唯一性 | 统计页面 `<h1>` 数量 | 有且仅有一个 | ✅ 脚本 |
| 标题层级跳级 | 按顺序检查 h1→h6 层级 | 无跳级 | ✅ 脚本 |
| 语义区块标签使用 | 检查 header/nav/main/footer/article/section 存在 | 关键区块使用语义标签 | ✅ 脚本 |
| div 滥用 | 检查 div 数量占比及可替换为语义标签的 div | div 占比合理 | ✅ 脚本 |
| 列表语义 | 检查是否用 div 模拟列表 | 使用 ul/ol | ✅ 脚本 |
| 表格语义 | 检查是否用 div 模拟表格 | 使用 table | ✅ 脚本 |

## 自动化检查

### 规范抽查（当前主要）

- 检查脚本：`workflow/scripts/semantic-spec-check.mjs`（06/07/08 三项规范一次抽查；抽样范围与解析口径见 measures/08-image-alt/检测方式.md）
- 执行方式：`node workflow/scripts/semantic-spec-check.mjs`
- 检测口径：
  - h1 数量不为 1（s.h1Count，必选）：静态 HTML 中 `<h1>` 计数为 0 或 >1
  - 标题层级跳级（s.headingSkip，必选）：按文档顺序 h1→h6，出现 `hN` 后直接跳到 `h(N+2)` 及更深
  - 语义区块：缺 `<main>`（s.noMain，必选）；缺 `<nav>`/`<footer>`（warn）；`<div>` 数与 7 类区块数在报告"规模"行输出
  - 客户端渲染壳（s.clientShell，必选）：静态 HTML 无链接/图片/实质 DOM（CSR SPA），语义结构对搜索引擎/AI 不可见
  - 列表/表格 div 模拟：脚本不自动判定，见下方人工检查要点
- 输出：`workflow/stats/semantic-spec-stats.json` + `manual-review/issues/semantic/YYYY-MM-DD-html语义化-抽查报告.md`

### 基线统计（仅站点首页）

- 检查脚本：`workflow/scripts/check-tag-structure.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/tag-structure-stats.json`

## 人工检查要点

- 自定义组件是否使用语义标签包裹
- 标题层级是否在动态内容中跳级
