## 规范定义

| 规范点 | 必选 | 规范说明 |
|--------|------|----------|
| 标题层级 | 是 | 每页有且仅有一个 `<h1>`，标题层级递进不跳级（h1→h2→h3），不用于样式 |
| 语义化区块标签 | 是 | 使用 `<header>`/`<nav>`/`<main>`/`<article>`/`<section>`/`<aside>`/`<footer>` 替代纯 `<div>` |
| 列表语义 | 是 | 使用 `<ul>`/`<ol>`/`<li>`，非 `<div>` 堆叠 |
| 表格语义 | 是 | 使用 `<table>`/`<thead>`/`<tbody>`/`<th>`，非 `<div>` 模拟 |
| 表单语义 | 是 | 使用 `<label>` 关联控件，使用 `<fieldset>`/`<legend>` 分组 |
| 图文语义 | 是 | 图片用 `<figure>`/`<figcaption>`，时间用 `<time>`，强调用 `<strong>`/`<em>` |

**规范细节**

- `<header>`: 当 `<header>` 元素的上下文为 `<body>` 元素时，它定义了一个 `banner` 地标。当 HTML 标题元素是 `<article>`、`<aside>`、`<main>`、`<nav>` 或 `<section>` 元素的后代时，则不视为 `banner` 地标。
- `<footer>`: 无障碍角色为 `contentinfo`，如果是 `<article>`、`<aside>`、`m<a>in`、`<nav>` 或 `<section>` 元素的后代，则为 `generic`

> `banner` 角色用于定义全局的站点页眉，其中通常包含徽标（logo）、公司名称、搜索功能，还可能包含全局导航或标语。它通常位于页面顶部。
> 
> `contentinfo` 角色定义了一个页脚，其中包含版权信息、导航链接和隐私声明等识别信息，这些信息出现在网站内的每个文档中，该部分通常被称为页脚。每页应仅包含一个顶级“contentinfo”标记点角色。

## 关键要求

1. 每个页面必须有且仅有一个 `<h1>`，概括页面主旨
2. 标题层级不得跳级（h1 后不得直接出现 h3）
3. 页面结构区块应使用语义标签，AI 和搜索引擎依赖语义结构理解内容层次
4. 避免 div 堆砌，使用正确的语义元素表达内容含义
