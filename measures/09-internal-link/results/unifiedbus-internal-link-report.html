说明与方法论

  • 页面来源：packages/website/pages/ 全部 .vue（Nuxt 文件路由，跳过根 index.vue 重定向页）+ content/{zh,en}/news 资讯 Markdown + API 枚举的动态实例（规范 /docs/、白皮书 /white-papers/、会议回放 /meeting/replay/）。
  • 链接提取：模板 href/:href/:to、TS 对象属性（href/url/path/link/software_link/backUrl）、编程式导航（navigateTo/router.push/router.replace/redirect/window.open）、模板字符串（locale 变量展开为 zh+en）、引号站内路径字面量；页面 import 链递归 6 层（含 Nuxt 自动导入组件与 composable）。backUrl（definePageMeta）由 AppHeaderMobile 返回按钮消费；字符串变换 str.replace('/docs/', …) 第一参非目标 URL，不提取。
  • 动态模板页壳出链：模板 .vue（如 news/[...slug].vue → TheNewsDetail 面包屑 → /{locale}/news）的出链是每个实例页都渲染的公共 UI（面包屑/返回按钮），同时归属到模板节点与全部实例页（来源标注「模板页壳」）。
  • .content/ YAML（nav/home/learning/software/simulation）经 #content/ 虚拟模块接入：nav 链接归全局导航；home banner 的 href（资讯）与 id: UB-*（规范预览）归首页出边。
  • config/statement/{zh,en}/*.md 声明 Markdown：TheStatement 组件按 category 静态绑定渲染到隐私/Cookie/使用条款等声明页，其中的 Markdown 链接（如 privacy → 个人信息收集清单/第三方共享清单/cookies）归入对应声明页出边。
  • 全局导航：layouts/default.vue 引用链（AppHeader/AppHeaderMobile/AppFooter/CookieNotice → .content/nav）中的链接单独归为「全局导航」，不注入到每页出边，避免指标失真。
  • API 补充：/api-server/web/v1/docs（规范，base 2.0.0 + 最新版）、/api-server/web/v1/white-paper（白皮书）、/api-meeting/meeting/（会议回放，仅历史会议），补充首页→文档/白皮书/回放、版本页→各文档的动态内链。可通过 SKIP_API=1 跳过。
  • 内链判定：www.unifiedbus.com 域名，或 /zh/…、/en/… 站内路径（无 locale 前缀的路径按 handleUrl 约定展开为 zh+en 两版）；/api-* 为接口、/category|/statement|/_ipx|/nav 等为资源，不计入。
  • 动态链接（含 ${…} 运行时变量）按位置匹配动态路由模板，边指向模板节点（代表全部实例）；guid/feedback 详情页等 id 驱动页面因此以模板节点出现。
  • 四类页面分类：孤岛=无内容链且未入导航；内容强·入口弱=有内容入链但不在导航；导航有·内容无=在导航但无内容入链；仅导航=无内容上下游但靠导航存活。
  • 管理/登录态页面（my/*、guid 管理/审核、feedback 审核/详情、meeting 创建/编辑、docs/license-agree、docs/mobile）可一键过滤，聚焦公开内容页的 GEO 内链优化。LOGIN_GUARD_LIST 为软守卫（await 登录不拦截），docs/guid/feedback 首页仍属公开内容页。
  • 重定向跳板页（definePageMeta redirect 或空模板 + onMounted 跳转，如 /guid、/legal、/software）无自身内容，跳转目标边保留，页面不计入孤岛/无入链统计。
  • 标题来源：资讯 frontmatter title、API title、页面 definePageMeta title.zh；其余显示路径。
  • 局限：error.vue 错误页、nuxt.config.ts llms/sitemap 链接未计入；活动（activity）API 当前无 href 字段未纳入；会议回放 URL 按当前会议数据快照枚举。
