# llms.txt 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-llms-txt | workflow/scripts/check-llms-txt.mjs | 校验各项目 /llms.txt 可访问性、结构完整性 | `node workflow/scripts/check-llms-txt.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-llms-txt.mjs

# 检查单个项目
node workflow/scripts/check-llms-txt.mjs --site openEuler-portal
```
