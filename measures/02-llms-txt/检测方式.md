# llms.txt 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| /llms.txt 可访问 | HTTP GET /llms.txt | 200 状态码 | ✅ 脚本 |
| Title 存在 | 解析 Markdown `#` 行 | 至少一行 H1 | ✅ 脚本 |
| Summary 存在 | 解析 Markdown `>` 行 | 至少一段引用摘要 | ✅ 脚本 |
| Links 完整 | 解析链接列表 | 绝对 URL，可访问 | ✅ 脚本 |
| robots.txt LLM-Policy | 检查 robots.txt | 包含指向 llms.txt 的声明 | ✅ 脚本 |

## 自动化检查

- 检查脚本：`workflow/scripts/check-llms-txt.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/llms-txt-stats.json`

## 人工检查要点

- llms.txt 内容是否准确反映站点核心信息
- Links 分组是否合理、链接是否可访问
- 内容是否随站点更新同步维护
