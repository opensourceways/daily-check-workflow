# llms.txt 规范

## 规范来源

- [llmstxt.org — The /llms.txt convention](https://llmstxt.org/)
- [Markdown for LLMs — proposal](https://blog.directory5000.com/llms-txt)
- 内部参考：robots.txt `LLM-Policy` 字段指向 llms.txt

## 规范定义

llms.txt 是部署在站点根目录 `/llms.txt` 的 Markdown 文件，专为 LLM 设计，提供结构化的站点摘要，使 AI 模型能高效理解站点内容并生成准确引用。

| 章节 | 必选 | 规范说明 |
|------|------|----------|
| Title | 是 | 以 `#` 开头的站点名称 |
| Summary | 是 | 简短的项目/站点描述（Block quote） |
| Info | 否 | 详细介绍段落 |
| Links | 是 | 按重要性分组的链接列表，格式 `[Title](URL): 描述`，必须为绝对 URL |
| Optional | 否 | 额外补充链接 |

## 文件结构示例

```markdown
# Site Name

> Brief summary of the project/site.

## Info
Optional detailed description.

## Links
### Core:
- [Getting Started](https://example.com/start): Quick start guide
- [Documentation](https://example.com/docs): Full documentation

### Optional:
- [Blog](https://example.com/blog): Latest updates
```

## 关键要求

1. 必须部署在根路径 `/llms.txt`
2. Title 和 Summary 必选
3. Links 必须为绝对 URL，按重要性分组
4. 内容应为 Markdown 纯文本，便于 LLM 解析
5. 与 robots.txt 的 `LLM-Policy` 字段联动
