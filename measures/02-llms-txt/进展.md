## 人工核验补充发现（脚本外项目）

1. **HTTP 发现头**：10 站全部缺失 `Link: rel="describedby"`（P1）与 `X-Llms-Txt`（P2）
2. **.well-known 别名损坏**：openUBMC 官网与 openGauss 文档返回 200 但内容为 HTML 页面（SPA/VitePress 兜底路由），比 404 更易误导工具；其余站点 404
3. **跨域 LLM-Policy**：openEuler 官网/文档 robots.txt 指向 `*.openeuler.openatom.cn`（镜像域，可访问但与主域不一致）；openGauss 官网指向非 www 域（其 llms.txt 内部链接也统一非 www，自洽）
4. **llms-full.txt 结构差异**：仅 openUBMC 文档有规范的 per-page 结构（标题+URL+Language）；openEuler 文档/openGauss 为 `--- URL ---` 或 frontmatter `url:` 形式（无独立标题行）；openEuler 文档内含相对图片路径 `./figures/…`（跨上下文不可解析）
5. **llms-full.txt 体积**：openGauss 文档 89MB、openEuler 文档 50MB、openUBMC 两站约 19MB（规范不设上限，但建议裁剪至 latest + LTS 版本）
