# JSON-LD 检测方式

## 检测项

| 检测项 | 检测方式 | 预期结果 | 自动化 |
|--------|----------|----------|--------|
| JSON-LD 存在 | 解析页面 script[type="application/ld+json"] | 至少一条 P0 schema | ✅ 脚本 |
| P0 必加项 | 解析 @type | Organization / BreadcrumbList / WebSite 齐全 | ✅ 脚本 |
| 必填属性完整 | 校验各 schema 必填字段 | 齐全且非空 | ✅ 脚本 |
| 取值真实 | 对比页面可见内容 | 无编造数据（评分/价格/日期） | 🟡 半自动 |
| JSON 语法合法 | JSON.parse | 无语法错误 | ✅ 脚本 |
| Google 富媒体测试 | 人工/链接 Rich Results Test | 无错误 | ❌ 人工 |

## 自动化检查

- 检查脚本：`workflow/scripts/check-jsonld.mjs`
- 执行方式：`node workflow/scripts/run-all.mjs` 或单独执行
- 输出：`workflow/stats/jsonld-stats.json`

## 人工检查要点

- AI 生成的 JSON-LD 取值是否与页面可见内容一致
- 占位符是否在发布前移除
- 使用 [Google Rich Results Test](https://search.google.com/test/rich-results) 验证
