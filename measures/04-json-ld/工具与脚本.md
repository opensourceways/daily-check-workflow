# JSON-LD 工具与脚本

## 相关脚本

| 脚本 | 路径 | 功能 | 使用方式 |
|------|------|------|----------|
| check-jsonld | workflow/scripts/check-jsonld.mjs | 校验各项目页面 JSON-LD 完整性、schema 类型覆盖、必填属性 | `node workflow/scripts/check-jsonld.mjs` |

## 使用说明

```bash
# 检查所有项目
node workflow/scripts/check-jsonld.mjs

# 检查单个项目
node workflow/scripts/check-jsonld.mjs --site openEuler-portal
```
