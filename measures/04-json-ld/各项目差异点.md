## 实现方式差异（实测推断）

| 模式 | 站点 | 特征 |
|------|------|------|
| 站点级全套注入 | openUBMC 官网/文档 | WebPage+CollectionPage+WebSite+Organization+BreadcrumbList+WebPageElement 完整 @graph |
| 页面级注入（缺站点级） | openEuler 文档、openGauss 文档、MindSpore 官网 | 仅 BreadcrumbList/Article 等页面节点 |
| 混合 | openEuler 官网、openGauss 官网、UnifiedBus、HiFloat | 部分页面有 Organization/WebSite，首页覆盖不一 |
| 特殊类型 | openEuler 官网（Report）、openEuler 文档（HowTo）、openGauss 官网（LearningResource）、MindSpore 官网（ItemList）、openUBMC 官网（Brand） | 各站自行扩展，类型选择不统一 |

## 共性问题

- 6/10 站首页无 JSON-LD；文档类站点普遍缺 Organization/WebSite 站点级节点
- Article/TechArticle 必填字段不全（image、datePublished、author）
- 类型选择不统一：同类页面（文档页/关于页）各站用不同 schema 类型
- 原进展记录与实测不符：原标 ✅ 的站点均为部分覆盖；原标 ❌ 的 UnifiedBus、openUBMC 官网已有部署

## 待统一项

- 全部站点按规范 P0 补齐：首页 + Organization + WebSite + BreadcrumbList 全站覆盖
- 文档页统一使用 TechArticle（headline ≤110 字符 + image ≥1200px + datePublished + author）
- 同类页面类型统一（关于页 Organization、文档页 TechArticle、下载页 SoftwareApplication）
- openEuler 文档移除 HowTo（富媒体已废弃）
- 落地方式统一：VitePress → transformPageData hooks；Nuxt → nuxt-schema-org；受限 → skill 兜底脚本（见工具与脚本）
