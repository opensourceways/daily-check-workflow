说明与方法论

  • 页面来源：pages/{zh,en} 静态路由（含 definePageMeta alias，排除鉴权目录 my/）、content/{zh,en} 内容路由（经 [id].vue 动态页 + queryContent 渲染）、/{l}/version/latest 特殊路由、SIG 清单 API（32 个详情页）。
  • 动态路由模板（cve/security-advisories/video/marketplace/edit-meeting，共 25 个）由运行时 API 驱动且 prerender:false，不纳入图。
  • 链接提取：md 正文/frontmatter、HTML href、NuxtLink :to、router.push/replace、YAML URL 字段（.content/ 经 #content/ 虚拟模块）、视图组件链（显式 import + Nuxt 自动导入，递归 5 层，组件索引来源：.nuxt/components.d.ts）。
  • locale 补全：复现 handleLocaleHref 语义 —— 去 locale 路径（如 /news）同时生成 /zh+/en 两份与页面集匹配。
  • i18n 富文本：locales/ 模块中 <a href> 按 t('ns.') 命名空间归属到使用该命名空间的页面。
  • 全局导航：layouts/default.vue 注入的 AppHeader2/AppHeaderMobile2/AppFooter/FloatingButton/FloatingLeft/AppGuide 中的链接单独归为「全局导航」，不注入到每页出边，避免指标失真（AppFooter 仅消费 home yaml 的 footer_links/friend_links 字段）。
  • 合成边：内容列表页 → 内容页（item._path 运行时数据按内容路由枚举合成）、SIG 列表 → SIG 详情（API 清单合成）。
  • 标题来源：content md frontmatter title、definePageMeta title、locales/route（按 Nuxt 路由名推导）、SIG 名。
  • 内链判定：以 www.openubmc.cn / openubmc.cn 域名，或 /zh/…、/en/… 站内路径（去 locale 路径双语言展开后匹配）。
  • 四类页面分类：孤岛=无内容链且未入导航；内容强·入口弱=有内容入链但不在导航（建议加导航/加链接）；导航有·内容无=在导航但无内容入链（建议补内容内链）；仅导航=无内容上下游但靠导航存活。
  • 局限：语言切换器（HeaderLang 的 zh/en 路径互换）、ProseImg docs-update 热区、版本切换器（OSelect 无 <a>）不计入；cve/security-advisories 等表格内的 API 动态链接未合成，需结合线上 HTML 抓取复核。
