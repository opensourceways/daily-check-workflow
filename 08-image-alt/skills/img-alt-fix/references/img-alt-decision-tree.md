# 1. 图片是否包含文字？

是：

- **并且该文字在附近也以真实文本形式存在：** 使用空的 alt 属性。参见 [装饰性图片](./img-types.md)。
- **并且该文字仅用于视觉效果：** 使用空的 alt 属性。参见 [装饰性图片](./img-types.md)。
- **并且该文字具有特定功能，例如是一个图标：** 使用 alt 属性来说明图片的功能。参见 [功能性图片](./img-types.md)。
- **并且图片中的文字在其他地方没有出现：** 使用 alt 属性包含图片中的文字。参见 [文字图片](./img-types.md)。

否：继续。

# 2. 图片是否用在链接或按钮中，且如果没有这张图片，就很难或无法理解该链接或按钮的作用？

是：使用 alt 属性来说明链接的目标或所执行的操作。参见 [功能性图片](./img-types.md)。

否：继续。

# 3. 图片是否为当前页面或上下文提供了意义？

是：

- **并且它是一张简单的图形或照片：** 在 alt 属性中用简短的描述传达该含义。参见 [信息性图片](./img-types.md)。
- **并且它是一张图表或复杂的信息呈现：** 将图片中包含的信息在页面其他位置给出。参见 [复杂图片](./img-types.md)。
- **并且它展示的内容与附近的真实文本重复：** 使用空的 alt 属性。参见 [功能性图片](./img-types.md)。

否：继续。

# 4. 图片是否纯粹用于装饰，或者并非面向用户？

是：使用空的 alt 属性。参见 [装饰性图片](./img-types.md)。
