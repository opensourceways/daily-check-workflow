# 图片类型

> 原文：[Images Tutorial](https://www.w3.org/WAI/tutorials/images/)

- 信息性图片：以图形方式表达概念和信息的图片，通常是图画、照片和插图。替代文本至少应是一段简短的描述，传达图片所呈现的关键信息。

- 装饰性图片：当图片的唯一作用是为页面添加视觉装饰，而非传达对理解页面而言重要的信息时，提供空的替代文本（alt=""）。

- 功能性图片：作为链接或按钮使用的图片，其替代文本应描述链接或按钮的功能，而非图片的视觉外观。例如：用打印机图标表示打印功能，或用按钮表示提交表单。

- 文字图片：有时可读文字会以图片形式呈现。如果图片不是徽标（logo），应避免在图片中使用文字。但如果确实使用了文字图片，替代文本应包含与图片中相同的文字内容。

- 复杂图片（如图表和图解）：为了传达数据或详细信息，应在替代文本中提供图片所含数据或信息的完整文字等价内容。

- 图片组：如果多张图片共同传达一条信息，其中一张图片的替代文本应传达整个图片组的信息。

- 图像映射（image map）：包含多个可点击区域的图片，其替代文本应为整组链接提供总体上下文。此外，每个单独的可点击区域都应有描述该链接用途或目标的替代文本。
